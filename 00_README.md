# Lekcja 20 - Projekt: Książka adresowa - Zadania

## Opis projektu

Książka adresowa to projekt łączący wszystkie dotychczas poznane koncepcje:
- Struktury (przechowywanie danych kontaktu)
- Funkcje (modularność kodu)
- Dynamiczne tablice/vector (przechowywanie wielu kontaktów)
- Praca z plikami (trwałe przechowywanie danych)
- Menu i obsługa użytkownika

## Przegląd zadań (etapy projektu)

| Nr | Nazwa | Poziom | Opis |
|----|-------|--------|------|
| 01 | Struktura Kontakt | ⭐ | Definicja struktury danych |
| 02 | Menu aplikacji | ⭐ | Interfejs użytkownika |
| 03 | Dodawanie i lista | ⭐⭐ | Dynamiczna kolekcja kontaktów |
| 04 | Wyszukiwanie | ⭐⭐ | Znajdowanie kontaktów |
| 05 | Edycja i usuwanie | ⭐⭐⭐ | Pełna manipulacja danymi |

## Cele dydaktyczne

Po wykonaniu projektu uczestnik potrafi:
- Projektować struktury danych dla rzeczywistych problemów
- Tworzyć interaktywne aplikacje konsolowe
- Zarządzać dynamicznymi kolekcjami danych
- Implementować podstawowe operacje CRUD
- Zapisywać i odczytywać dane z plików
